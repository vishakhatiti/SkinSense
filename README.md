# SkinSense 🌿

SkinSense is a web-based recommendation system that suggests suitable **organic soaps** and **herbal shampoos** based on user skin and hair concerns using a **rule-based approach**.

The project aims to promote natural personal care products by helping users choose the right product according to their specific needs.

---

## 🔍 Features

- Recommends organic soaps based on different skin types and skin concerns  
- Suggests herbal shampoos based on common hair problems  
- Rule-based recommendation logic implemented using JavaScript  
- Simple, clean, and user-friendly interface  
- Fully responsive static website

## ⚙️ How It Works

1. The user selects their skin or hair concerns through the interface  
2. JavaScript applies predefined rule-based conditions  
3. The system matches user input with suitable organic products  
4. Recommended soap or shampoo is displayed instantly
